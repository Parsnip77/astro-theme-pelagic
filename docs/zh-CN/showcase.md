# 截图与效果

以下截图来自未经修改的英文与简体中文示例内容。[leanderc.com](https://leanderc.com) 展示的是个人博客版本，后续可能包含更多定制。

[English](../showcase.md)

## 主页

![桌面端主页](../images/home-desktop.jpg)

主页有意不加入大幅图片、个人卡片或仪表盘，只保留站点标题、导航、文章列表以及语言和主题切换。

## 文章与侧边目录

![桌面端文章页](../images/article-desktop.jpg)

宽屏下正文适当左移，在右侧为目录留出独立空间；窄屏下则恢复为常规单栏阅读布局。

## 公式、代码与图表

![公式、代码与 Mermaid 示例](../images/features-desktop.jpg)

KaTeX、代码高亮、Mermaid 和宽表格使用独立的排版尺度。超宽图表与表格会横向滚动，不会把文字不断缩小到难以阅读。
